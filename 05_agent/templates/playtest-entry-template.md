# Playtest Entry Template

## Purpose

Use this template when recording a structured playtest finding in `08_testing/playtest-notes.md`.

## Template

Date

YYYY-MM-DD

Build / Ruleset State

Short identifier or description.

Testers

Names or shorthand.

Focus

What system or scenario was being tested.

Setup

Any special setup conditions, shortcuts, or assumptions.

What Happened

Factual description of what occurred.

What Felt Strong

What worked well.

What Felt Bad

What felt wrong, confusing, weak, or frustrating.

Interpretation

Classify as:

- design success
- design failure
- tuning issue
- clarity issue
- setup issue
- unknown / needs repeat
