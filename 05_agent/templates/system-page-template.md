# System Page Template

## Purpose

Use this template when creating or heavily revising a system page under `06_design/systems/`.

## Template

[System Name]
Purpose

What this system is for and why it exists in Neo UO.

Player Experience Goal

What the player should feel or understand when interacting with this system.

Design Position

How Neo UO approaches this system in principle.

Core Doctrine

List the key laws or non-negotiable rules for the system.

Intended Feel

Describe the emotional and gameplay target.

MVP Version

Describe the smallest version that still proves identity.

Later Expansion Version

Describe what should come only after the MVP version is directionally successful.

Design Risks

List the main ways this system could fail or drift.

Implementation Notes

List likely implementation concerns, prototype boundaries, or architecture guidance.

Open Questions

List unresolved questions that should be answered later.

Current Direction

Summarize the present intended direction in a concise way.
