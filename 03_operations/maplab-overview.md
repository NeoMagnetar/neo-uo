# MapLab Overview

## Purpose
Provide a neutral operational surface for map-pipeline artifacts before anything is promoted into Dev or Staging.

## Path
- `C:\UO\Server\Neo Ultima Online\MapLab`

## Subfolders
- `Imports` = incoming editor outputs or imported map artifacts
- `Exports` = produced outputs for review
- `Snapshots` = map-pipeline safety snapshots
- `Diffs` = comparison outputs and changed-file sets

## Intended use
Use MapLab as a staging/workbench area for terrain/static editing artifacts instead of dropping map-pipeline files directly into live shard roots.
