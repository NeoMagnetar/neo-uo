# Decision Principles

## Principle 1 — Preserve the Center

Do not add systems that make Neo UO feel like a standard shard with extra knobs.

## Principle 2 — Prefer Legible Depth

Danger can be high, but systems must remain learnable enough for mastery.

## Principle 3 — Favor World Memory

Characters, items, rivalries, rescues, deaths, and territories should matter beyond the moment.

## Principle 4 — Avoid Parallel Truth Sources

The repo should have one clear source of truth for each domain:

- doctrine in `00_governance`
- design in `06_design`
- execution state in `04_tasks`
- testing in `08_testing`
- architectural notes in `02_architecture`

## Principle 5 — Build the Smallest Version That Proves the Identity

The MVP should prove the doctrine, not attempt the full dream immediately.
