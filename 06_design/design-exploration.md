# Design Exploration

## Purpose

This file exists to preserve the broader Neo UO design space discussed during planning conversations.

It is not a final rules document.
It is not a locked implementation document.
It is a memory and direction document.

Its role is to capture:

- ideas discussed
- variants under consideration
- tensions between systems
- experimental targets
- aspirational mechanics that may arrive later
- ideas that are important enough to remember even if not yet actionable

## Usage Rule

Anything in this file should be understood as one of the following:

- active design direction
- exploratory idea
- future-phase concept
- unresolved but important design thought
- experimentation target

Nothing here should be treated as final balance or guaranteed implementation unless separately promoted into formal doctrine or prototype planning.

## Core Exploration Themes

### 1. Survival-War Identity

Neo UO is exploring how to make UO feel more like a lived-in survival-war world rather than a standard shard with harsher penalties.

### 2. Meaningful Death Without Full Player Ejection

The project is exploring ways to preserve real stakes while avoiding total player deflation after major loss.

### 3. Drawn-Out Consequence Rather Than Instant Reset

The game is exploring combat, wounds, movement, and recovery systems that create prolonged danger and survival stories.

### 4. Sparse World, Higher Meaning

The wilderness is being imagined as lower-density but more behaviorally meaningful, with less noise and more tension.

### 5. Political and Social Memory

The project is exploring how guilds, heroes, captures, rescues, and famous items can become part of world history.

## Idea Preservation Categories

### Ideas With Strong Directional Support

These ideas fit the current project center well:

- slower, more consequential combat
- backup-character continuity
- wound states instead of pure instant reset
- clue-based tracking
- lower creature density
- stronger logistical pressure
- burden and route importance
- guild heroes and political leverage
- arena as detached but related lane

### Ideas Under Consideration But Not Locked

These require experimentation or more thought:

- how much survivability to add overall
- how much healing to reduce
- how high the long-term skill cap should go
- how visible and systemic famous-item pressure should be
- how capture should resolve
- how strong wildlife pursuit should be
- how much stash freedom is healthy
- how deeply arena should mirror world combat layers

### Ideas Likely Later-Phase

These fit the world but should arrive much later:

- full capture/rescue systems
- prisoner exchange systems
- renowned-item circulation pressure
- attackable strongholds
- tower-defense-like fortifications
- deity-driven utility layers
- deeper political territory systems

## Current Preservation Rule

If an idea:

- supports the Neo UO center
- has been discussed enough to matter
- but is not ready to finalize

it should be captured somewhere in this repo rather than left only in chat history.

## Current Direction

This file should become the umbrella memory page for Neo UO’s larger idea-space while more specific experimental details live in the related system pages.
