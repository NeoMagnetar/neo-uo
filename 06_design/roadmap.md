# Roadmap

## Phase 0 — Foundation and Documentation

Goal:
Create a stable project headquarters and a coherent doctrine set.

Deliverables:

- repo structure stabilized
- governance and design pages populated
- roadmap and task lane initialized
- testing lane initialized

## Phase 1 — Playable Local Baseline

Goal:
Get a reliable local Neo UO build running for core iteration.

Deliverables:

- local shard boot and test workflow
- two-player local testing support
- first combat sanity pass
- first progression sanity pass

## Phase 2 — Death, Continuity, and Progression Core

Goal:
Implement the systems that make Neo UO feel different at the life-value level.

Deliverables:

- character death-routing design
- continuity after loss structure
- safe vs dangerous training rules
- early wound and recovery prototype
- early backup-character design translation

## Phase 3 — Hunt and Combat Identity

Goal:
Make conflict and wilderness traversal feel like Neo UO.

Deliverables:

- tracking redesign prototype
- anti-zerg mana-pressure prototype
- drawn-out combat tuning
- recovery and wound interaction tuning
- ecology / scarcity first pass
- burden and movement-pressure first pass

## Phase 4 — Closed Playtest

Goal:
Test the doctrine against real behavior.

Deliverables:

- small controlled tester group
- playtest note capture
- balance findings
- issue and redesign review

## Phase 5 — Arena Mode Prototype

Goal:
Prove the detached combat lane without contaminating the main world.

Deliverables:

- first arena ruleset
- mode separation rules
- practice / onboarding value

## Phase 6 — World Expansion Systems

Goal:
Deepen the world once the core identity is validated.

Deliverables:

- improved PvE reward structure
- hidden stash systems
- stronger bounty logic
- renowned-item logic
- capture / rescue design
- more role-expression tools

## Phase 7 — Strongholds and Siege Layer

Goal:
Make territory and political warfare materially real.

Deliverables:

- attackable strongholds
- defensive proxy systems
- repair / breach rules
- tower-defense experiments
- territory pressure loops
