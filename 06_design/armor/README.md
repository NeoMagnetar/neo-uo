# Armor

This folder is the Armor wiki for Neo UO.

It exists to preserve armor-family memory, protection identity, loadout context, Neo UO relevance, and future testing direction. This is a design and wiki layer, not a final balancing pass and not an implementation-truth source.

## Structure
- `armor-index.md` groups the armor pages by family and notable type.
- `armor-era-matrix.md` tracks the core armor pages in one table.
- `armor-design-principles.md` records how Neo UO wants to think about armor overall.
- `armor-balance-philosophy.md` records how armor should be reviewed later.
- `families/` contains the main armor-family pages.
- `notable-types/` contains loadout and comparison pages that help future tuning work.
