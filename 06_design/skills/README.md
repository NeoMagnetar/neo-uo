# Skills

This folder is the Skills wiki for Neo UO.

It exists to preserve design memory, compare UO skill baselines, track Neo UO relevance, and give future testing and code work a stable place to attach notes. This is a design and wiki layer, not a final balancing pass and not a code-truth mirror.

## What belongs here
- baseline role of each skill
- era or expansion origin
- Neo UO relevance
- experimentation targets
- future testing notes
- future code reference pointers

## What does not belong here
- final tuning claims
- implementation truth duplicated from the code repo
- empty placeholder-only pages

## Structure
- `skill-index.md` groups the full skill set by family.
- `skill-expansion-matrix.md` tracks every skill in one table.
- `skill-design-principles.md` records the broad Neo UO approach to skills.
- `skill-balance-philosophy.md` records how skills should be reviewed before future changes.
- `skills/` contains one flat wiki page per skill.
