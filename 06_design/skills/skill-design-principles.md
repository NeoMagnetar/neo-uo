# Skill Design Principles

Neo UO should think about skills as long-lived character identity, not disposable short-term optimization.

## Current principles
- Slower mastery should matter more than rushed completion.
- Characters should be able to stay broad and long-lived without every skill collapsing into sameness.
- Dangerous-world growth should matter; travel, risk, and field utility are part of skill value.
- Utility and counterplay matter alongside direct throughput.
- Expansion-era skills should be preserved in the wiki even where Neo UO direction is still open.
- No final tuning is assumed in this layer.

## Working rule
This wiki preserves direction and questions first. Testing and code work can tighten specifics later.
