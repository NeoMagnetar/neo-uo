# Skill Balance Philosophy

Neo UO should review skills as part of a wider world and character ecology, not only through duel math or convenience training.

## Review lenses
- Survival value in a dangerous world.
- Utility value outside direct damage races.
- Anti-zerg interactions and counterplay.
- Progression depth for long-lived characters.
- Arena separation where relevant so world identity is not flattened into match tuning.
- World-vs-safe training implications.

## Constraint
This file does not finalize balance. It records how future balance review should be framed.
