# Weapons

This folder is the Weapons wiki for Neo UO.

It exists to preserve weapon-family memory, later-era combat context, Neo UO relevance, and future testing direction. This is a design and wiki layer, not a final balancing pass and not an implementation-truth source.

## Structure
- `weapon-index.md` groups the weapon pages by family and notable type.
- `weapon-era-matrix.md` tracks the core weapon pages in one table.
- `weapon-design-principles.md` records how Neo UO wants to think about weapons overall.
- `weapon-balance-philosophy.md` records how weapons should be reviewed later.
- `families/` contains the main weapon-family pages.
- `notable-types/` contains subtype and comparison pages that help future tuning work.
