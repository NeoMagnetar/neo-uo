# Phase 1 Test Plan

## Goal
Confirm that the phase 1 enforcement shell behaves consistently inside the Britain graveyard test region.

## Checks
- Entering the region triggers arena messaging.
- Leaving the region clears arena-specific messaging or state as intended.
- Mount use is blocked or corrected inside the region.
- Recall is blocked inside the region.
- Gate travel is blocked inside the region.
- Region boundary behavior is stable and understandable.

## Acceptance standard
Phase 1 is acceptable when the rules shell is predictable, portable, and not entangled with unfinished mode logic.
