# Arena Rules Profiles

## Concept
An arena rules profile is a reusable rules package that can be assigned to multiple arena region instances.

## Why profiles matter
Profiles keep the rules portable. The Britain graveyard test region can use one profile now, and a larger arena region can use the same profile later without rewriting the design model.

## Phase 1 expectation
The first profile should cover the phase 1 enforcement shell only: region awareness, no mounts, no recall, no gate travel, entry and exit handling, and rules messaging.

## Future direction
Later profiles may add stronger travel restrictions, death handling, or mode-specific behavior, but those belong to later phases.
