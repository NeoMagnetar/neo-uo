# ServUO Touchpoints

## Purpose
This file stores implementation-facing references that design work may need when handing off to the code repo.

## Current touchpoints
- Region-based law is the preferred enforcement direction.
- Travel restriction handling should point toward spell or travel-law surfaces, not ad hoc coordinate checks.
- Mount restriction handling should be treated as reusable arena law, not a graveyard-only special case.

## Boundary
This file is a reference bridge only. Final implementation planning belongs in the code repo.
