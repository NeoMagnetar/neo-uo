# Britain Graveyard Test Region

## Role
The Britain graveyard test region is the first controlled test footprint for the portable arena rules framework.

## Why this region exists
It provides a small, observable arena boundary where the phase 1 enforcement shell can be tested before a larger arena region is built.

## What it is not
This region is not the permanent identity of the arena system. It is a first arena region instance used to validate rules structure and behavior.

## Phase 1 focus
Use this region to confirm entry and exit handling, no mounts, no recall, no gate travel, and clear rules messaging.
