# Arena Overview

## Purpose
The Arena section defines a portable arena rules framework that can start in a small test footprint and later expand into larger arena region instances without changing the organizational model.

## Phase 1 boundary
Phase 1 is the enforcement shell only. It establishes arena law and region behavior, not a full match loop.

## First test region
The Britain graveyard test region is the first controlled footprint because it is easy to reach and inspect. It should not become the permanent code identity of the arena system.

## Durable asset
The durable asset is the reusable law layer plus reusable arena rules profiles. Future arena modes should sit on top of that layer.
