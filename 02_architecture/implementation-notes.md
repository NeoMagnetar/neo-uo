# Implementation Notes

## Purpose

Hold technical notes that connect design doctrine to likely implementation paths.

## Early Notes

- death logic should be implemented as a state-aware system, not scattered special cases
- recovery should likely distinguish current health from wound-state capacity
- tracking should move from certainty to evidence-driven outputs
- creature density reduction should be paired with stronger encounter behavior, not only fewer spawns
- capture should be handled as a character state, not as forced live imprisonment
