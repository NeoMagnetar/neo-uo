# Repo File Map

## Purpose

This file describes what each root lane is for and prevents content sprawl.

## Root Lane Map

- `00_governance` — project laws and decision standards
- `01_logs` — project history and notable decisions
- `02_architecture` — repo map, codebase audit, file targets
- `03_operations` — how to run and manage project workflows
- `04_tasks` — what is active, planned, blocked, and complete
- `05_agent` — reusable machine-facing handoffs and workflows
- `06_design` — PRD, roadmap, and game-system doctrine
- `07_umg` — UMG project context as it applies to Neo UO
- `08_testing` — local and playtest observations
- `09_reference` — glossary and comparison framing
