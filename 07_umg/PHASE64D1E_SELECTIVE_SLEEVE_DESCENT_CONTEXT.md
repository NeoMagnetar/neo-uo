# Phase64D1E UMG Context

Phase64D1E turns a saved approved Operational Layout into a runtime Preview decision without changing saved configuration.

## Spine

Always-On nodes remain active for Governance, Identity, Capability Truth, System Invariants, Operational Authority, Owner/Commander Authority, Safety, and Logging.

## Families

Foreground families are:

- Combat
- Positioning
- Resources
- Protection

Each family may select zero or one `ActivePreview` branch. Different families may select simultaneously. Losing eligible siblings are suspended only in the receipt.

## Gates

- Capability gates derive from actor state and deterministic services.
- Governance gates preserve stop, hold, follow, hunt, travel, stand-down, cancellation, control epoch, and movement ownership priority.
- Draft layouts never participate in the normal runtime.

## Receipts

Receipts report trigger matches, candidate branches, selected branch by family, suspension, blocked branches, typed intent, adapter mapping, cognition budget, warnings, errors, and final result.

Final result remains `PREVIEW_ONLY_NOT_DISPATCHED`.
