# Project UMG Context

## Purpose

Record how UMG-style structured thinking is being applied to Neo UO.

## Current Use

UMG is being used here primarily as:

- a documentation and planning structure aid
- a doctrine-separation aid
- a way to keep governance, system design, execution tracking, and testing distinct

## Rule

UMG context should support the project’s clarity, not replace the project’s actual game design content.
