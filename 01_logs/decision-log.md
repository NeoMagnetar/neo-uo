# Decision Log

## Decision 001

Use the existing numbered root lanes as the canonical repo architecture.

Reason:
The repo already established a root-lane grammar. Adding a second parallel documentation universe would fragment project truth.

## Decision 002

Treat Neo UO as a survival-war sandbox, not as a conventional UO shard with hardcore modifiers.

Reason:
This is the clearest articulation of the product identity and the strongest filter for future systems.

## Decision 003

Separate design intent from execution tracking.

Reason:
The PRD and roadmap should describe what the project aims to become. Active work status belongs in task tracking files, not in the design doctrine itself.
