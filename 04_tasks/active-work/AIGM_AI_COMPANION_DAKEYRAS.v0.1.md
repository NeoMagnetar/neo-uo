# AIGM AI Companion — Dakeyras v0.1

## Purpose
Create the first embodied AI companion actor that can move, follow, and later fight and equip gear like a true in-world companion.

## Why this lane exists
The GM counselor shell is good for admin/chat/inspection, but movement and combat fit much better on a dedicated embodied actor.

## Initial v0.1 scope
- spawn Dakeyras
- follow me
- stop following
- come here
- baseline companion equipment/inventory compatibility
- starting skills:
  - Archery
  - Healing
  - Fencing
  - Magic Resist

## Design note
This is a separate role from the counselor.

- counselor = command / planning / admin shell
- Dakeyras = embodied companion actor

## Future direction
This opens the path to:
- equipping weapons and armor
- combat / escort behavior
- skill use and growth
- item pickup and interaction
- later richer AI autonomy
